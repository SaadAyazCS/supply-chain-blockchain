# 🚀 Blockchain-Based Supply Chain Tracking System

## 📌 Overview
This project is a **Blockchain-Based Supply Chain Tracking System** developed to improve transparency, security, and traceability in supply chains.  
It uses **Hyperledger Fabric** to store product data in a decentralized and tamper-proof ledger.

---

## 🎯 Problem Statement
Traditional supply chain systems face issues like:
- Lack of transparency  
- Data tampering  
- Fraud and trust issues  
- Difficulty in tracking product history  

---

## 💡 Solution
This system assigns a **unique ID** to each product and records every stage of its journey on the blockchain.  
All stakeholders can track product movement in a secure and transparent way.

---

## ✨ Key Features
- 🔍 Track products using unique ID  
- 📜 Complete product history visibility  
- 🔐 Secure and tamper-proof blockchain storage  
- 👨‍💼 Admin can add new products  
- 🚚 Supply chain members can update status  
- 👤 Customers can verify product authenticity  

---

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Python  
- **Blockchain:** Hyperledger Fabric  


---

## ⚙️ How It Works
1. Admin adds a product with a unique ID  
2. Each stakeholder updates product status  
3. Data is stored on blockchain  
4. Users can track full product history anytime
