# Supply Chain Blockchain System

## Description
This project is a blockchain-based supply chain tracking system using Hyperledger Fabric.

## Features
- Track products using unique ID
- Transparent history of product
- Secure and tamper-proof data

## Technologies Used
- HTML, CSS, JavaScript
- Python
- Hyperledger Fabric
